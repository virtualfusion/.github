# Security policy

Virtual Fusion takes the security of its platform and its customers' data seriously. Thank you for helping us keep it safe.

## Reporting a vulnerability

Please report security issues privately. Do not open a public issue, pull request or discussion.

- Use GitHub private vulnerability reporting: https://github.com/virtualfusion/.github/security/advisories/new
- Include what you found, where (product area, URL or repository), the steps to reproduce it, and the impact you expect.
- Please do not access, change or keep data that is not yours, and do not run tests that could degrade the service for others.

## What happens next

- We acknowledge a report within 3 business days.
- We keep you informed while we investigate and fix it, and agree with you when the issue can be disclosed.
- We credit reporters who want to be credited once the fix is out.

## Scope

All Virtual Fusion services, applications and repositories in this organisation.
